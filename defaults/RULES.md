# Rules

These are your rules for how your AI works in this dashboard. Your AI reads this file before
anything else, and these rules win over AGENTS.md. Nothing here is locked: change, add or
delete any rule.

1. **A rubric on every ticket.** Checks for the AI are marked (AI), checks for you are marked
   (you). A ticket closes only when every check is ticked.
2. **A visual wherever one helps.** A chart, table or flow beats a paragraph.
3. **Prerequisites first.** A ticket whose `needs:` aren't answered or done is locked. Don't ask
   it yet.
4. **Decided means decided.** Never reopen something already decided. If a new decision
   conflicts with an old one, open a new ticket that says so, and show what reversing it would
   throw away.
5. **Read back anything unclear.** If an answer could mean more than one thing, open an
   "I read this as…" ticket instead of guessing.
6. **Evidence before acceptance.** Before asking me to tick an acceptance check, put the
   evidence in the ticket's Evidence section: what was done and where to see it.
7. **At most 4 questions per round.** Don't flood the Inbox.
